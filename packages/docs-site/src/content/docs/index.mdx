Typeroll CMS is an open-source CMS with a visual editor, a REST API and an MCP
server. Use the browser editor for content changes, or connect your own AI agent
to build and manage sites. You can start editing and reviewing previews before
connecting publishing accounts.

## Cloud or self-hosting

These docs cover both ways to run Typeroll CMS. Start with
[Using Typeroll Cloud](guides/typeroll-cloud/) for the managed service or
[Self-hosting](guides/self-hosting/) to run the CMS yourself. The
[workflow comparison](getting-started/cloud-and-self-hosting/) links to the shared
guides and explains differences in setup, availability and responsibility.

## Software, hosting and connected services

The open-source edition is free to self-host. Infrastructure and connected
services have their own costs. [Typeroll Cloud](https://typeroll.com/) is the
managed service; its user guides live here alongside the shared CMS and
self-hosting instructions. Cloud access and service limits are separate from
the open-source license.

Published sites are static files. Forms, Apps and Extensions can call separate
runtime services. See [Cloudflare hosting and builds](publishing/cloudflare/)
for the boundary between source code, build execution and hosting. You can also
[serve independently generated sections on one domain](publishing/multiple-generators/).

## Documentation for your agent

Use [llms.txt](llms.txt) as the documentation index, or
[llms-full.txt](llms-full.txt) for the complete text. The index also links to a separate text version of every
page, so your agent can fetch only what it needs. Text exports contain absolute
links and source addresses and do not require JavaScript or a login. These files describe the
product; they do not grant access to your sites. API and MCP requests still need
your credentials and the appropriate permissions.
