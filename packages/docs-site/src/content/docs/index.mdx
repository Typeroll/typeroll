## What you can do

<CardGrid>
  <Card title="Create full sites" icon="rocket">
    Settings, header/footer, all pages, and deploy — Claude handles the entire
    setup from a single prompt.
  </Card>
  <Card title="Compose with blocks" icon="puzzle">
    ~40 reusable blocks cover the 95% case — hero, feature grids, pricing,
    testimonials, galleries, forms. Custom blocks ship through Claude too, and
    headings shrink fluidly on mobile by default.
  </Card>
  <Card title="Import existing content" icon="document">
    Migrate from WordPress, Squarespace, Wix, Webflow or any URL. Content is
    cleaned and adapted to your design automatically.
  </Card>
  <Card title="Blogs, forms, directories" icon="list-format">
    Collection schemas, listing pages, contact forms with HMAC protection — all
    wired up by the AI in minutes.
  </Card>
  <Card title="SEO built in" icon="magnifier">
    Meta descriptions, Open Graph images, JSON-LD structured data, robots.txt —
    one audit pass, everything fixed.
  </Card>
</CardGrid>
