---
title: Blog and article sites
description: Build articles and archive pages with one Page model and a shared template.
---

Use the bundled `tr-blog` recipe with your AI agent. Every article is a Page
whose content type supplies custom fields, routing and a shared template.

1. Create a reusable Page template, using the article or blog starting layout.
2. Create an Articles content type with its URL pattern and default template.
3. Create one Page per article, with native body blocks and custom values in `fields`.
4. Add `core/page_list` to an archive Page and optional homepage teaser.
5. Preview desktop/mobile layouts, save working copies and publish the approved version.

The listing automatically reflects saved Pages at the next build. Articles use
the same editor, history, preview, status controls and API as every other Page.
See [Content types and Page templates](../../tools/content-types/) for tools,
examples, routing, references and version behavior.
