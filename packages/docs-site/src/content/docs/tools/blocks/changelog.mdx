---
title: "Block changes by Core version"
description: "When block features and behaviour arrived, by Core release, for self-hosted installations that run an older Core."
---

The block reference pages describe the current behaviour. This page records
the Core release that introduced each change, so a self-hosted installation on
an older Core can tell what it supports. Typeroll Cloud always runs the current
release. Check `get_site_capabilities` and `read_block_type` on the connected
site rather than relying on a version number alone.

Behaviour that depends on a site's [render version](../../settings/#render-versions)
is described on the reference pages themselves, because it changes per site.
